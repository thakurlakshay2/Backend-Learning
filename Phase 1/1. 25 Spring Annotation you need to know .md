# 25 Spring Annotations You Actually Need to Know

## TL;DR

| #   | Annotation               | Category   | One-Line Meaning                                                      |
| --- | ------------------------ | ---------- | --------------------------------------------------------------------- |
| 1   | `@SpringBootApplication` | Bootstrap  | Boots the app: auto-config + component scan + config, combined        |
| 2   | `@Component`             | Bean       | Generic marker: "Spring, manage this class as a bean"                 |
| 3   | `@Service`               | Bean       | `@Component` for the business-logic layer (semantic only)             |
| 4   | `@Repository`            | Bean       | `@Component` for data access + auto exception translation             |
| 5   | `@Controller`            | Web        | Marks a class as an MVC request handler, returns view names           |
| 6   | `@RestController`        | Web        | `@Controller` + `@ResponseBody`: returns JSON, not views              |
| 7   | `@Configuration`         | Config     | Marks a class that declares `@Bean` methods; proxies inter-bean calls |
| 8   | `@Bean`                  | Config     | Declares a single bean, returned from a method                        |
| 9   | `@Autowired`             | DI         | Tells Spring to inject a dependency automatically                     |
| 10  | `@Qualifier`             | DI         | Picks a specific bean when multiple candidates match a type           |
| 11  | `@Value`                 | Config     | Injects a value from properties/environment into a field              |
| 12  | `@ComponentScan`         | Config     | Tells Spring which packages to scan for `@Component` classes          |
| 13  | `@RequestMapping`        | Web        | Maps a URL (and optionally HTTP method) to a handler                  |
| 14  | `@GetMapping`            | Web        | Shortcut for `@RequestMapping(method = GET)`                          |
| 15  | `@PostMapping`           | Web        | Shortcut for `@RequestMapping(method = POST)`                         |
| 16  | `@PutMapping`            | Web        | Shortcut for `@RequestMapping(method = PUT)`                          |
| 17  | `@DeleteMapping`         | Web        | Shortcut for `@RequestMapping(method = DELETE)`                       |
| 18  | `@PathVariable`          | Web        | Binds a URL path segment to a method parameter                        |
| 19  | `@RequestParam`          | Web        | Binds a query-string parameter to a method parameter                  |
| 20  | `@RequestBody`           | Web        | Deserializes the HTTP request body into a Java object                 |
| 21  | `@Entity`                | Data       | Marks a class as a JPA-managed database table mapping                 |
| 22  | `@Id`                    | Data       | Marks the primary-key field of an `@Entity`                           |
| 23  | `@Transactional`         | Data       | Wraps a method in a database transaction (commit/rollback)            |
| 24  | `@ExceptionHandler`      | Web        | Catches a specific exception thrown inside a controller               |
| 25  | `@Scheduled`             | Scheduling | Runs a method automatically on a fixed interval/cron                  |

## The 25, In Detail

### 1. `@SpringBootApplication`

**Meaning:** Combines three annotations into one — `@SpringBootConfiguration`, `@EnableAutoConfiguration`, and `@ComponentScan`. It's the annotation on your `main` class that boots the entire app.

```java
// Before — no @SpringBootApplication: nothing is wired, nothing runs
public class MyApp {
    public static void main(String[] args) { }
}
```

```java
// After
@SpringBootApplication
public class MyApp {
    public static void main(String[] args) {
        SpringApplication.run(MyApp.class, args);
    }
}
```

**Uses:** Application entry point, in every Spring Boot project. [Example: Phase0Application.java](../src/main/java/com/example/phase0/Phase0Application.java)
**Docs:** [SpringBootApplication (Javadoc)](https://docs.spring.io/spring-boot/docs/current/api/org/springframework/boot/autoconfigure/SpringBootApplication.html)

---

### 2. `@Component`

**Meaning:** The base marker that tells Spring "create and manage this class as a bean." Every other stereotype (`@Service`, `@Repository`, `@Controller`) is itself annotated with `@Component` — that's how component scanning finds them too.

```java
// Before — a plain class Spring doesn't know about
public class SlugGenerator {
    public String slugify(String s) { return s.toLowerCase().replace(" ", "-"); }
}
```

```java
// After — Spring creates and manages it, available for injection
@Component
public class SlugGenerator {
    public String slugify(String s) { return s.toLowerCase().replace(" ", "-"); }
}
```

**Uses:** Generic utility/helper beans that don't fit a more specific stereotype. [Example: DemoComponent.java](../src/main/java/com/example/phase0/demo/DemoComponent.java)
**Docs:** [Component (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/stereotype/Component.html)

---

### 3. `@Service`

**Meaning:** Functionally identical to `@Component` — it exists purely to label the business-logic layer so the codebase's architecture is readable at a glance.

```java
@Service
public class PricingService {
    public BigDecimal applyDiscount(BigDecimal price, double pct) {
        return price.subtract(price.multiply(BigDecimal.valueOf(pct)));
    }
}
```

**Uses:** Business rules, calculations, orchestration across multiple repositories. [Example: UserService.java](../src/main/java/com/example/phase0/service/UserService.java)
**Docs:** [Service (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/stereotype/Service.html)

---

### 4. `@Repository`

**Meaning:** `@Component` for the data-access layer — with one real functional addition: it enables Spring's exception translation, converting raw database exceptions into a consistent, unchecked `DataAccessException`.

```java
// Before — plain JDBC exceptions leak out to callers
public class OrderDao {
    public Order findById(String id) throws SQLException { /* ... */ }
}
```

```java
// After — Spring translates SQLException into DataAccessException for you
@Repository
public interface OrderRepository extends JpaRepository<Order, String> { }
```

**Uses:** DAOs, Spring Data JPA repository interfaces. [Example: DemoRepository.java](../src/main/java/com/example/phase0/demo/DemoRepository.java)
**Docs:** [Repository (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/stereotype/Repository.html)

---

### 5. `@Controller`

**Meaning:** Marks a class as a Spring MVC handler. Methods return a **view name** by default (e.g., a Thymeleaf template), not raw data.

```java
@Controller
public class HomeController {
    @GetMapping("/")
    public String home() {
        return "home"; // resolves to home.html / home.jsp
    }
}
```

**Uses:** Server-rendered web pages, not JSON APIs. [Example: HomeController.java](../src/main/java/com/example/phase0/controller/HomeController.java)
**Docs:** [Controller (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/stereotype/Controller.html)

---

### 6. `@RestController`

**Meaning:** `@Controller` + `@ResponseBody` bundled together — every method's return value is serialized directly into the HTTP response body (usually JSON) instead of being resolved as a view name.

```java
// Before — @Controller alone tries to resolve "OK" as a view name → error
@Controller
public class StatusController {
    @GetMapping("/status")
    public String status() { return "OK"; }
}
```

```java
// After — returns the literal string "OK" as the response body
@RestController
public class StatusController {
    @GetMapping("/status")
    public String status() { return "OK"; }
}
```

**Uses:** REST/JSON APIs — the default for almost all modern backend endpoints. [Example: UserController.java](../src/main/java/com/example/phase0/controller/UserController.java)
**Docs:** [RestController (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/web/bind/annotation/RestController.html)

---

### 7. `@Configuration`

**Meaning:** Marks a class whose job is to declare beans via `@Bean` methods. By default, Spring generates a CGLIB proxy so that if one `@Bean` method calls another within the same class, it returns the same cached singleton instead of a new object.

```java
@Configuration
public class AppConfig {
    @Bean
    public RestTemplate restTemplate() {
        return new RestTemplate();
    }
}
```

> [!WARNING]
> Swapping `@Configuration` for `@Component` on a class where one `@Bean` method calls another silently breaks singleton behavior — each call then creates a new instance instead of reusing the cached one.

**Uses:** Java-based configuration classes, replacing old XML bean definitions. [Example: SecurityConfig.java](../src/main/java/com/example/phase0/config/SecurityConfig.java)
**Docs:** [Configuration (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/context/annotation/Configuration.html)

---

### 8. `@Bean`

**Meaning:** Declares a single Spring-managed bean, typically inside a `@Configuration` class — useful for objects you don't own the source of (third-party libraries) and can't annotate directly with `@Component`.

```java
// Before — a third-party class you can't add @Component to
ObjectMapper mapper = new ObjectMapper(); // created manually, not managed

// After
@Configuration
public class JacksonConfig {
    @Bean
    public ObjectMapper objectMapper() {
        return new ObjectMapper().registerModule(new JavaTimeModule());
    }
}
```

**Uses:** Registering third-party or manually-constructed objects as Spring beans. [Example: SecurityConfig.java](../src/main/java/com/example/phase0/config/SecurityConfig.java)
**Docs:** [Bean (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/context/annotation/Bean.html)

---

### 9. `@Autowired`

**Meaning:** Tells Spring to resolve and inject a dependency automatically instead of constructing it manually.

```java
// Before — manual, tightly-coupled construction
public class OrderService {
    private OrderRepository repo = new OrderRepository();
}
```

```java
// After — Spring injects the managed bean (constructor injection preferred)
@Service
public class OrderService {
    private final OrderRepository repo;

    @Autowired // optional on a single constructor since Spring 4.3
    public OrderService(OrderRepository repo) {
        this.repo = repo;
    }
}
```

**Uses:** Wiring dependencies between beans. Prefer constructor injection over field injection — it makes the class testable without the Spring container. [Example: PaymentService.java](../src/main/java/com/example/phase0/demo/PaymentService.java)
**Docs:** [Autowired (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/beans/factory/annotation/Autowired.html)

---

### 10. `@Qualifier`

**Meaning:** Disambiguates which bean to inject when more than one bean matches the required type.

```java
// Before — ambiguous: two PaymentGateway beans exist, Spring can't choose
@Autowired
private PaymentGateway gateway; // throws NoUniqueBeanDefinitionException
```

```java
// After
@Autowired
@Qualifier("stripeGateway")
private PaymentGateway gateway;
```

**Uses:** Multiple implementations of the same interface registered as beans. [Example: PaymentService.java](../src/main/java/com/example/phase0/demo/PaymentService.java)
**Docs:** [Qualifier (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/beans/factory/annotation/Qualifier.html)

---

### 11. `@Value`

**Meaning:** Injects a value from `application.properties`/`application.yml`, environment variables, or a SpEL expression, directly into a field or parameter.

```java
// application.properties
// app.max-upload-size=10

@Component
public class UploadConfig {
    @Value("${app.max-upload-size}")
    private int maxUploadSizeMb;
}
```

**Uses:** Pulling externalized configuration into beans without a full `@ConfigurationProperties` class. [Example: AppPropertiesDemo.java](../src/main/java/com/example/phase0/demo/AppPropertiesDemo.java)
**Docs:** [Value (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/beans/factory/annotation/Value.html)

---

### 12. `@ComponentScan`

**Meaning:** Tells Spring which package(s) to scan for `@Component`-annotated classes. Implicitly included in `@SpringBootApplication`, scanning the current package and sub-packages by default.

```java
@Configuration
@ComponentScan(basePackages = "com.example.orders")
public class AppConfig { }
```

**Uses:** Explicitly widening or restricting where Spring looks for beans — needed when beans live outside the main application's package tree. [Example: ComponentScanConfig.java](../src/main/java/com/example/phase0/config/ComponentScanConfig.java)
**Docs:** [ComponentScan (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/context/annotation/ComponentScan.html)

---

### 13. `@RequestMapping`

**Meaning:** The general-purpose annotation mapping a URL path (and optionally an HTTP method) to a controller or handler method. The `@GetMapping`/`@PostMapping`/etc. family are shortcuts built on top of it.

```java
@RestController
@RequestMapping("/api/orders")
public class OrderController {
    @RequestMapping(value = "/{id}", method = RequestMethod.GET)
    public OrderDto get(@PathVariable String id) { /* ... */ }
}
```

**Uses:** Class-level base path declarations; method-level mapping when you need more control than the shortcut annotations offer. [Example: UserController.java](../src/main/java/com/example/phase0/controller/UserController.java)
**Docs:** [RequestMapping (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/web/bind/annotation/RequestMapping.html)

---

### 14. `@GetMapping`

**Meaning:** Shortcut for `@RequestMapping(method = RequestMethod.GET)`.

```java
@GetMapping("/orders/{id}")
public OrderDto getOrder(@PathVariable String id) { /* ... */ }
```

**Uses:** Any read-only endpoint. [Example: UserController.java](../src/main/java/com/example/phase0/controller/UserController.java)
**Docs:** [GetMapping (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/web/bind/annotation/GetMapping.html)

### 15. `@PostMapping`

**Meaning:** Shortcut for `@RequestMapping(method = RequestMethod.POST)`.

```java
@PostMapping("/orders")
public OrderDto createOrder(@RequestBody CreateOrderRequest req) { /* ... */ }
```

**Uses:** Creating a new resource. [Example: UserController.java](../src/main/java/com/example/phase0/controller/UserController.java)

**Uses:** Full replacement update of an existing resource. [Example: UserController.java](../src/main/java/com/example/phase0/controller/UserController.java)

### 18. `@PathVariable`

**Meaning:** Binds a segment of the URL path to a method parameter.

```java
// GET /orders/123 → id = "123"
@GetMapping("/orders/{id}")
public OrderDto getOrder(@PathVariable String id) { /* ... */ }
```

**Uses:** Any endpoint identifying a specific resource by ID in the URL. [Example: UserController.java](../src/main/java/com/example/phase0/controller/UserController.java)
**Docs:** [PathVariable (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/web/bind/annotation/PathVariable.html)

### 19. `@RequestParam`

**Meaning:** Binds a query-string parameter to a method parameter.

```java
// GET /orders?status=SHIPPED
@GetMapping("/orders")
public List<OrderDto> getOrders(@RequestParam(required = false) String status) { /* ... */ }
```

**Uses:** Filtering, pagination, optional query options. [Example: UserController.java](../src/main/java/com/example/phase0/controller/UserController.java)
**Docs:** [RequestParam (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/web/bind/annotation/RequestParam.html)

### 20. `@RequestBody`

**Meaning:** Deserializes the incoming HTTP request body (typically JSON) into a Java object.

```java
// Before — manually parsing the raw request body
public OrderDto create(HttpServletRequest req) {
    String json = readBody(req); // manual, error-prone
    CreateOrderRequest dto = objectMapper.readValue(json, CreateOrderRequest.class);
}
```

```java
// After — Spring deserializes it for you
@PostMapping("/orders")
public OrderDto create(@RequestBody CreateOrderRequest req) { /* ... */ }
```

**Uses:** `POST`/`PUT` endpoints accepting a JSON payload. [Example: RequestBodyDemoController.java](../src/main/java/com/example/phase0/controller/RequestBodyDemoController.java)
**Docs:** [RequestBody (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/web/bind/annotation/RequestBody.html)

### 21. `@Entity`

**Meaning:** A JPA (Jakarta Persistence) annotation marking a class as mapped to a database table. Not Spring-specific, but essential in almost every Spring Boot + JPA project.

```java
@Entity
@Table(name = "orders")
public class Order {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String status;
}
```

**Uses:** Defining the object-relational mapping layer for Spring Data JPA. [Example: DemoEntity.java](../src/main/java/com/example/phase0/demo/DemoEntity.java)
**Docs:** [Jakarta Persistence — @Entity (Javadoc)](https://jakarta.ee/specifications/persistence/3.1/apidocs/jakarta.persistence/jakarta/persistence/entity)

---

### 22. `@Id`

**Meaning:** Marks the primary-key field of an `@Entity`.

```java
@Entity
public class Customer {
    @Id
    @GeneratedValue(strategy = GenerationType.UUID)
    private String id;
}
```

**Uses:** Required on every JPA entity — Spring Data JPA needs it to generate `findById`, `save`, etc. [Example: DemoEntity.java](../src/main/java/com/example/phase0/demo/DemoEntity.java)
**Docs:** [Jakarta Persistence — @Id (Javadoc)](https://jakarta.ee/specifications/persistence/3.1/apidocs/jakarta.persistence/jakarta/persistence/id)

---

### 23. `@Transactional`

**Meaning:** Wraps a method in a database transaction — commits if it completes normally, rolls back automatically on an unchecked exception.

```java
// Before — two separate writes, no atomicity guarantee
public void transfer(String fromId, String toId, BigDecimal amount) {
    accountRepo.debit(fromId, amount);
    accountRepo.credit(toId, amount); // if this throws, the debit already committed
}
```

```java
// After — both writes succeed or both roll back together
@Transactional
public void transfer(String fromId, String toId, BigDecimal amount) {
    accountRepo.debit(fromId, amount);
    accountRepo.credit(toId, amount);
}
```

**Uses:** Any service method performing multiple related writes that must succeed or fail together. [Example: TransactionDemoService.java](../src/main/java/com/example/phase0/demo/TransactionDemoService.java)
**Docs:** [Transactional (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/transaction/annotation/Transactional.html)

---

### 24. `@ExceptionHandler`

**Meaning:** Marks a method that catches a specific exception type thrown within a controller (or globally, when combined with `@ControllerAdvice`), letting you return a clean, structured error response instead of a default stack trace.

```java
// Before — an unhandled exception returns a raw 500 with a stack trace
@GetMapping("/orders/{id}")
public OrderDto getOrder(@PathVariable String id) {
    return orderService.findById(id); // throws OrderNotFoundException
}
```

```java
// After
@ExceptionHandler(OrderNotFoundException.class)
public ResponseEntity<ErrorResponse> handleNotFound(OrderNotFoundException ex) {
    return ResponseEntity.status(HttpStatus.NOT_FOUND)
        .body(new ErrorResponse(ex.getMessage()));
}
```

**Uses:** Consistent, structured error responses instead of default framework error pages. [Example: ExceptionHandlingDemoController.java](../src/main/java/com/example/phase0/controller/ExceptionHandlingDemoController.java)
**Docs:** [ExceptionHandler (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/web/bind/annotation/ExceptionHandler.html)

---

### 25. `@Scheduled`

**Meaning:** Runs a method automatically on a fixed delay, fixed rate, or cron expression — no external scheduler needed.

```java
@Component
public class CleanupTask {
    @Scheduled(cron = "0 0 2 * * *") // every day at 2 AM
    public void purgeExpiredSessions() {
        sessionRepository.deleteAllExpired();
    }
}
```

**Uses:** Recurring background jobs (cleanup, report generation, cache refresh) without a separate job scheduler like Quartz. [Example: ScheduledDemoTask.java](../src/main/java/com/example/phase0/demo/ScheduledDemoTask.java)
**Docs:** [Scheduled (Javadoc)](https://docs.spring.io/spring-framework/docs/current/javadoc-api/org/springframework/scheduling/annotation/Scheduled.html)
